# 财务语义约束与有限筛查

本轮处理昨晚报告中“数值有来源、解释或派生定义错误”的问题。Windows `D:\TradingAgents` 是运行仓库；保留旧报告和模型原文，不通过改写历史报告制造验收成功。

## 实现范围

1. 基本面分析师每次请求都收到财务规则；其报告存在时，研究、交易和风险角色通过共享 instrument context 收到同一规则。约束包括币种/数量级、现金流期间、净现金定义、应收款分类、收益率重复计数、融资和损益原因的证据边界。
2. 确定性摘要只在同一资产负债表日同时存在现金及等价物行和 `Total Debt` 时计算两者差额，完整标明原始字段和来源单位。支持Yahoo的 `Cash And Cash Equivalents` 及SEC的 `Cash and Equivalents` 两个实际字段名，输出保留所用原始名称。缺当前债务不使用旧期债务、流动负债或总负债替代。即使可计算，也要求核查债务范围和受限现金后才能称净现金。
3. 基本面报告追加程序复核提示，原始 AIMessage 不改写。有限中英规则筛查以下表述：期间不明的现金流被称作单季/Q1–Q4、现金减流动负债被称作净现金、报表缺债务行却量化净现金、未声明单位的报表被明确称作“以人民币元计”、其他应收款被解释成客户预收款、FCF收益率加股息率被称作总回报。
4. 命中使用 `financial-semantics: REVIEW` 标记，未命中使用 `LIMITED_CHECK`。后者只意味着这几条规则没有命中，不能表示所有事实通过。程序追加的提示不计入阶段正文长度，避免提示把短回复变成合格报告。
5. `run_rating` 对 REVIEW 报告返回 REVIEW，覆盖模型给出的 Buy/Hold 等评级，但保留原始模型文字和 typed rating。这一入口用于程序返回信号、状态日志、记忆记录；不会把待核实前提写成已认可方向。
6. 阶段闸门仍独立记录 ACCEPT/REJECT；另记录 `content_review`。受保护运行入口和独立验收器遇到财务 REVIEW 返回退出码2，保存证据并停止自动重跑。退出码0也只证明阶段/输入完整，不证明全文财务正确。

## 已知边界

这是提示约束和有限文本筛查，不是通用事实核验器。规则不是账户审计，也不穷尽所有金额、日期、表格和因果解释。净现金的缺字段提示只针对匹配的报表；若另一工具或附注提供完整债务定义，应由审阅者检查，而非直接断定数值伪造。

现金流规则关注同一短句中的现金流/资本开支与单季标签；收入季度不会仅因另一个短句提到现金流而被阻断。它不理解跨行表头和所有复杂否定表达。当前对包含显式否定/纠正词的行跳过筛查，混合“错误断言＋无关否定”的句子可能漏检；这是须继续改进的边界，不能据未命中认定真伪。

模型可能违反规则，或在后续辩论中产生新错误；本轮自动筛查只处理基本面分析师正文。任何自动放行都不表示全文财务内容已获事实验收。本轮不重新付费跑完整四股分析；旧报告重放与离线回归也不是修复后新模型效果的证据。

## 定义依据

净债务/净现金必须明确债务范围并与报表核对；“债务”没有唯一统一口径，不能把流动负债直接替换为债务。参考 [IFRS Foundation关于融资负债披露的说明](https://www.ifrs.org/news-and-events/news/2019/02/feature-changes-in-financing-liabilities/)。该文属于解释材料，不把它当作贵州茅台适用会计准则的直接依据。

股东实际回报需要区分价格变化和分配收入，FCF收益率不等于新增分红回报。参考 [Investor.gov账户收益说明](https://www.investor.gov/better-understanding-your-brokerage-account-statement)。
